# Daily Games Hub — privacy policies

Public hosting for the Daily Games Hub privacy policies:

- Firefox: https://helloworld9099.github.io/daily-games-hub-privacy/firefox/privacy.html

Both pages are the exact files built into the extension packages (`dist/privacy.html`), with the
support link and canonical URL injected from `release-metadata.json` in the extension repository.
